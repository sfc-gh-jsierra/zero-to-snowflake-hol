TASTY BYTES · FOOD TRUCKS GLOBALES

Zero to Snowflake: de los fundamentos a los agentes de IA

Objetivo: recorrer Snowflake de punta a punta en un solo workshop: desde SQL basico y warehouses hasta un agente de Snowflake CoWork que responde preguntas de negocio y se consume desde apps Streamlit y React.

90 minutos
Nivel Introductorio a Intermedio
11 labs
Comenzar con el Lab 0

Que vas a construir

Lo que vas a construir

  • Un ambiente con mas de 900 millones de filas de ventas de Tasty Bytes
  • Fundamentos: warehouses elasticos, cache, clonacion y Time Travel
  • Un pipeline semi-estructurado con Dynamic Tables
  • IA con SQL (Cortex AISQL) sobre texto, audio, documentos e imagenes
  • Gobierno con Horizon y datos de Marketplace sin ETL
  • Una Semantic View y un Cortex Search Service
  • Un agente de Snowflake CoWork que elige sus herramientas
  • Dos apps que consumen el agente: Streamlit y React

Tecnologias utilizadas

Workspaces Dynamic Tables Cortex AISQL Horizon Marketplace Semantic Views Cortex Search Cortex Analyst Snowflake CoWork Cortex Code (CoCo) Streamlit in Snowflake Snowflake App Runtime

Por que importa

De SQL basico a un agente de IA en produccion, todo dentro de Snowflake: sin mover datos, con gobierno aplicado y con el mismo motor sirviendo analitica, IA y aplicaciones.

Requisitos

Navegador

Chrome, Edge o Firefox actualizado. Todo se hace desde Snowsight.
